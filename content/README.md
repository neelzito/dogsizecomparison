# Site content

Everything outside the comparison tool is generated by `node tools/build_site.js`.
Run it after changing breed data (`js/breeds.js`) or anything in this folder.
The output folders (`breeds/`, `compare/`, `sizes/`, `groups/`, `origins/`,
`articles/`, `calculators/`, `about/`) are wiped and rewritten on every run, so
don't edit the generated HTML by hand.

- `articles/<slug>.md` → `/articles/<slug>/`. Front matter: `title` (the `<title>`),
  `h1`, `description`, `lede`, optional `date`. Body is simple Markdown (`##` headings,
  paragraphs, lists, tables, `> note`, links). A line `{{name}}` inserts a generated
  block; see `contentBlocks()` in `tools/build_site.js` for the list.
- `breeds/<breed-id>.md` (optional) → adds an "About the <breed>" section to that
  breed's page. The id is the URL slug, e.g. `breeds/beagle.md`. Use it for real,
  hand-written text: temperament, history, care. That is what makes breed pages
  stand out from data-only pages.
- `about.md` → `/about/`.
- `airlines.json` → airline cabin table, the airline calculator and the flying guide.
  Update `reviewed` whenever you check the rules again.

Ranked lists (smallest, tallest, heaviest, longest-living) are written in
`rankedArticles()` in `tools/build_site.js`. Comparison pairs live in
`tools/site/content-data.js`; every breed also gets a pair with its closest
same-group neighbour automatically.
